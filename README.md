## 🚀 Quick Start

Run the server with a single command (using Python 3's built-in standard library, no dependencies required):

```bash
cd "journal-club"
./start.sh
```

Or manually:
```bash
python3 server.py
```

Then open **[http://localhost:8080](http://localhost:8080)** in your browser.

> **Offline & GitHub Pages mode:** You can also open `index.html` directly in any web browser without running a server. Data is stored in your browser's local storage.
